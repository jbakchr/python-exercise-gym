# Manipulation

## Overview

The goal of the Manipulation stage is to start using decorators to solve practical problems.

In the previous stages, you learned:

- How decorators work
- How decorators wrap functions
- How to handle arguments and return values
- How to preserve metadata
- How to create flexible decorators

Now it is time to apply that knowledge.

Instead of focusing on decorator mechanics, this stage focuses on building decorators that provide useful functionality.

Many of the exercises in this stage mirror decorators that are commonly found in real-world applications and frameworks.

---

## Learning Goals

By the end of this stage you should be able to:

- Use decorators to add behavior to existing functions
- Create reusable utility decorators
- Measure function execution time
- Log function activity
- Debug function calls
- Modify and validate function outputs
- Track usage statistics
- Combine multiple decorator techniques

---

## What You Will Practice

Topics covered in this stage:

- Timing execution
- Debugging
- Logging
- Output manipulation
- Input validation
- Function monitoring
- Reusable utilities
- Combining behaviors

---

## Recommended Approach

For every exercise:

1. Read the challenge carefully.
2. Attempt a solution without looking at hints.
3. Experiment with your own variations.
4. Refactor and improve your solution.
5. Compare against the provided solution.
6. Reflect on what you learned.
7. Move on only when the concept feels comfortable.

Remember:

```text
Working code is the starting point.
Understanding why it works is the goal.
```

## Exercises

### 21 Timer Decorator

Create a decorator that measures how long a function takes to execute.

---

### 22 Debug Decorator

Create a decorator that displays information before and after a function call.

---

### 23 Logger Decorator

Create a decorator that records function execution details.

---

### 24 Uppercase Output

Create a decorator that modifies a function's returned text and converts it to uppercase.

---

### 25 Result Formatter

Create a decorator that formats return values before they are displayed.

---

### 26 Argument Validator

Create a decorator that validates incoming arguments before execution.

---

### 27 Execution Counter

Create a decorator that tracks how many times a function has been called.

---

### 28 Parameter Checker

Create a decorator that checks whether supplied parameters meet defined rules.

---

### 29 Combining Behaviors

Apply multiple decorators to the same function and explore how they interact.

---

### 30 Build a Debug Toolkit

Create a reusable collection of decorators for:

- Logging
- Timing
- Debugging
- Call tracking

This exercise acts as the capstone for the Manipulation stage.

## Success Criteria

You are ready to continue to the next stage when:
