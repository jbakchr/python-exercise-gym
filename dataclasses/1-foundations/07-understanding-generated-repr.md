## Why This Matters

When working with objects, developers often need to inspect their contents.

Without a useful representation, printing an object may produce output that is difficult to understand.

Dataclasses automatically generate a `__repr__()` method that displays the object's fields and values.

Example:

```text
Book(title='Python Basics', author='Jane Smith', pages=250)
```

This makes dataclass objects easier to inspect, debug, and understand.

In future exercises you will continue exploring other methods that dataclasses generate automatically.

## New Concept

Dataclasses automatically generate a `__repr__()` method.

When an object is printed, Python uses this method to create a readable representation.

Example:

```python
print(book)
```

Output:

```text
Book(title='Python Basics', author='Jane Smith', pages=250)
```

The generated representation includes:

- The class name
- Field names
- Field values
