## Why This Matters

Comparing objects is a common task in software development.

Examples include:

```text
Checking configuration values
Comparing API responses
Finding duplicate records
Verifying test results
```

Dataclasses automatically generate an `__eq__()` method that compares objects using their fields.

This means you often get useful comparison behavior without writing any extra code.

Understanding this behavior is an important step toward understanding the benefits of dataclasses.

## New Concept

Dataclasses automatically generate an equality method.

This allows objects to be compared using:

```python
==
```

Example:

```python
user_one == user_two
```

If every field contains the same value, the objects are considered equal.

No custom comparison code is required.
