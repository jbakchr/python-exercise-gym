## Why This Matters

When creating normal Python classes, developers often need to write an `__init__` method manually.

Dataclasses remove much of this boilerplate by generating one automatically.

Understanding this behavior is important because every dataclass object is created through the generated constructor.

This idea will help you understand future topics such as:

## New Concept

Normally, classes require an `__init__` method to receive values when an object is created.

Example:

```python
class Person:
    def __init__(self, name):
        self.name = name
```

Dataclasses generate this method automatically based on the fields you define.

```python
@dataclass
class Person:
    name: str
```

Python creates the constructor for you.
